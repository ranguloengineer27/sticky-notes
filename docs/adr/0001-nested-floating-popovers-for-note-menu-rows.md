# Nested floating popovers for note menu row expansion

The unified sticky note menu (`StickyNoteMenu`) shows each option (color, shape) collapsed to its current value inside an outer panel; clicking a collapsed value must reveal the other options for that row. The simpler default would have been to expand the row inline, growing the outer panel in place. Instead, each row expands into its own small floating popover anchored to its collapsed chip, layered over the rest of the outer panel — deliberately accepting a popover-inside-a-popover, plus the two-layer Escape/click-outside handling that comes with it (`useTogglePopover`'s `suppressEscape` option exists specifically for this). This was chosen to keep the outer panel's size fixed regardless of which row is expanded, and to stay visually consistent with the pre-existing `ShapesMenu` floating-panel style already used elsewhere in the app. Without this note, a future reader could reasonably "simplify" a row's expansion back to inline reflow, not realizing the layering was intentional.
